# 📝 Formulaire multi-étape

## Description

Ce projet consiste en la réalisation d'un formulaire web organisé en plusieurs étapes.

L'objectif est de permettre à l'utilisateur de remplir progressivement les différentes informations du formulaire avec une navigation entre les étapes.

## Fonctionnalités

* Formulaire organisé en plusieurs étapes
* Navigation entre les différentes étapes
* Saisie et récupération des informations
* Interface simple et interactive
* Gestion des interactions avec JavaScript

## Technologies utilisées

* HTML5
* CSS3
* JavaScript

## Structure du projet

* `index.html` : structure du formulaire
* `style.css` : mise en forme
* `script.js` : logique et interactions
* `README.md` : documentation du projet
